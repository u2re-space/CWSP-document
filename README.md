# CWSP-document

**CWSP-document** — документная поверхность U2RE для открытия, чтения, преобразования и выпуска Markdown-документов.

Это не только Markdown viewer: приложение умеет принимать файлы и текст из буфера, показывать исходник и отрендеренный документ, готовить материал к печати, экспортировать его в DOCX и работать вместе с Chrome-расширением CWSP-crx.

## Для чего нужен

CWSP-document подходит, когда нужно быстро:

- открыть `.md` / Markdown-документ;
- просмотреть его в аккуратном печатном виде;
- вставить Markdown из буфера обмена или перетащить файл в окно;
- переключиться между исходным текстом и рендером;
- скачать исходный Markdown, скопировать текст или передать документ в Work Center;
- распечатать документ или экспортировать его в `.docx`.

## Основные возможности

### Markdown и документы

- Открытие Markdown-файлов и просмотр в browser/PWA-поверхности.
- Drag-and-drop файлов и вставка текста из clipboard.
- Режимы **Raw** и **Rendered** для сверки исходника с результатом.
- Поддержка типичной структуры Markdown: заголовки, списки, таблицы, ссылки, код, изображения и математические блоки в поддерживаемом рендерере.
- Настройки внешнего вида документа и панели просмотра.

### Печать и экспорт

- Подготовка документа к системной печати через браузер.
- Экспорт Markdown в **DOCX**.
- Сохранение Markdown-файла и копирование исходного либо отрендеренного текста.
- Конвертация структурированных блоков, таблиц, ссылок, изображений и поддерживаемой математики в документ Word.

### Формулы и распознавание в Chrome

В связке с [`CWSP-crx`](../CWSP-crx/) доступен **CRX Snip**:

1. Откройте контекстное меню CWSP-crx или используйте его горячую клавишу.
2. Выделите область страницы с формулой, задачей, фрагментом текста или изображением.
3. Расширение сделает снимок выделенной области.
4. Если в Settings настроен AI-провайдер и инструкции распознавания, снимок отправляется в AI pipeline, а результат возвращается прямо в рабочий поток CWSP.

Таким способом можно распознавать формулы «на месте», не сохраняя скриншот вручную и не покидая текущую вкладку. Качество результата зависит от выбранной AI-модели, инструкции и читаемости исходного изображения.

CRX Snip также поддерживает режимы распознавания, решения задач, генерации кода, извлечения CSS и пользовательских инструкций. Для выбранного контента Chrome-расширение может копировать данные как Markdown, HTML, LaTeX или MathML.

## Поверхности

| Поверхность | Назначение |
| --- | --- |
| **CWSP-document / PWA** | Отдельная документная SPA для Markdown и печати. |
| **CWSP shell** | Viewer, Explorer, Editor, Settings и Print как части единого окружения. |
| **CWSP-crx** | Инструменты страницы: контекстное меню, Snip, захват области и AI-распознавание. |

Markdown-host включает представления `viewer`, `explorer`, `workcenter`, `editor`, `settings`, `history`, `home` и `print`.

## Как пользоваться

### Открыть документ

- Нажмите **Open** в панели Viewer и выберите файл.
- Перетащите документ в окно просмотра.
- Вставьте Markdown из буфера через **Paste**.

### Подготовить результат

- Используйте **Raw**, чтобы проверить исходный текст.
- Используйте **Style**, чтобы настроить отображение.
- Нажмите **DOCX**, чтобы выгрузить Word-документ.
- Нажмите **Print**, чтобы открыть системный диалог печати.

### Распознать формулу в браузере

- Установите и настройте CWSP-crx.
- Укажите AI-провайдер/модель в настройках CWSP.
- Запустите CRX Snip, выделите формулу и выберите режим распознавания.

Без настроенного AI провайдера CRX Snip всё ещё умеет выбрать и захватить область, но не может выполнить AI-распознавание.

## Структура

```text
apps/CWSP-document/
├── src/frontend/web/cw-markdown/  # отдельный Markdown/PWA entry point
├── src/frontend/views/            # Viewer, Editor, Explorer и shell-представления
├── src/shared/                    # настройки, routing и общая логика
└── README.md
```

Ключевые shared-модули workspace:

- `markdown-view` — viewer, toolbar и действия документа;
- `subsystem/other/document` — Markdown → HTML/DOCX и преобразование математики;
- `fest/fl-ui` — UI-компоненты, меню и панели;
- `fest/icon`, `fest/lure`, `fest/veela` — иконки, реактивный DOM и дизайн-токены;
- `CWSP-crx` — Chrome Manifest V3, content scripts и CRX Snip.

## Статус

CWSP-document активно развивается как локально-ориентированный документный слой U2RE: от быстрого просмотра Markdown до печати, DOCX-экспорта и AI-assisted анализа контента в браузере.
